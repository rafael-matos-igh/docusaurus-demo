# Welcome to Nimbus

**Nimbus** is a fictional task-queue platform used to demonstrate what a Docusaurus documentation site can look like.

:::info
This is a demo. Nimbus does not exist, and none of the code here will run against a real service.
:::

## What you'll find here

- [Getting started](getting-started/installation.md): install the CLI and run your first job.
- [Guides](guides/scheduling-jobs.md): task-oriented walkthroughs.
- [API reference](api/overview.md): endpoints, parameters and examples.

## Why Nimbus?

| Feature | Description |
| --- | --- |
| Reliable delivery | Jobs are retried with exponential backoff. |
| Scheduling | Cron expressions and one-off delayed jobs. |
| Observability | Built-in metrics and structured logs. |
